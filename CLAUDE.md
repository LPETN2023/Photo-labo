# CLAUDE.md — Photo labo (distribution)

Dépôt de distribution du logiciel Photo labo. Le code source est dans le dépôt `Photo_labo_source`
(voir son `CLAUDE.md`).

- Le programme n'est **plus versionné ici** : `build.bat` (dépôt source) produit `dist\Photo_Labo_vX.Y.zip`,
  publié dans une **Release GitHub** de ce dépôt (étiquette `vX.Y`, même numéro que `APP_VERSION`).
- Ce dépôt ne contient que `README.md` (lien vers la dernière Release), `.gitattributes`, `.gitignore`.
- L'historique Git contient encore les anciens binaires (~150 Mo) ; nettoyage possible mais il réécrit
  le dépôt : à décider avec l'utilisateur.
