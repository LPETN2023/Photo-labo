# Photo labo

Logiciel Windows de prise de vue des scellés : photos par procédure, scellé et catégorie,
depuis une webcam ou un téléphone Android (ADB).

Ce dépôt contient le programme prêt à l'emploi (`Photo Labo.exe` et ses dossiers).

## Installer (une seule fois)

```
git clone https://github.com/LPETN2023/Photo-labo.git
```

Puis lancer `Photo Labo.exe` dans le dossier `Photo-labo` obtenu.

## Mettre à jour

Fermer Photo Labo, puis dans le dossier `Photo-labo` :

```
git pull
```

Le mode d'emploi complet est dans `LISEZMOI.txt` du dépôt source `Photo_labo_source`.
