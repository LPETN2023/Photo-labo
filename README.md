# Photo labo

Logiciel Windows de prise de vue des scellés : photos par procédure, scellé et catégorie,
depuis une webcam ou un téléphone Android (ADB).

## Télécharger

Le programme se télécharge dans la page **[Releases](../../releases/latest)** de ce dépôt :

1. ouvrir la dernière version et télécharger `Photo_Labo_vX.Y.zip` ;
2. décompresser le zip où vous voulez (bureau, clé USB…) ;
3. lancer `Photo Labo.exe` dans le dossier obtenu.

Le mode d'emploi complet est dans `LISEZMOI.txt` du dépôt source `Photo_labo_source`.
